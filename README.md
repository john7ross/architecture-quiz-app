# Architecture Quiz App

Интерактивная платформа для проверки и получения знаний по архитектуре ПО, DDD, DocHub, AI и Computer Science. React-приложение с динамической загрузкой тем, светлой/тёмной темой и адаптивным интерфейсом.

**Живая версия:** https://john7ross.github.io/architecture-quiz-app

---

## Состояние банка вопросов

**5 тем × 200 вопросов = 1000 вопросов.** Все вопросы вычитаны на фактическую корректность, без дублей концепций, с разнообразием форматов (определения, сценарии, сравнения, «зачем», «какое утверждение верно», узнавание по описанию). У каждого вопроса 4 варианта ответа и развёрнутое объяснение.

| Тема | Файл | Вопросов | Сложность |
|------|------|----------|-----------|
| DocHub | `dochub.json` | 200 | intermediate |
| Domain-Driven Design | `ddd.json` | 200 | advanced |
| Software Architecture | `architecture.json` | 200 | advanced |
| AI & Automatization | `ai-automation.json` | 200 | intermediate |
| Computer Science | `computer-science.json` | 200 | beginner-advanced |

Инварианты, поддерживаемые в каждом файле: `id` идут подряд от 1 до N, нет повторяющихся `id`, ровно 4 варианта, `correct` в диапазоне 0–3, у каждого вопроса непустое `explanation`, нет дублей текста вопросов, позиции правильных ответов перемешаны (распределение по позициям сбалансировано).

## Возможности

- **Динамическая загрузка тем.** Каждая тема — отдельный JSON, который подгружается по требованию через dynamic import (webpack отдаёт его отдельным чанком). Количество вопросов в плитках считается на лету из самих файлов.
- **Светлая/тёмная тема.** Автоопределение по `prefers-color-scheme` при первом запуске, ручной переключатель, выбор сохраняется в `localStorage` и применяется как `data-theme` на `<html>`.
- **Переключатель темы на всех экранах.** Кнопка зафиксирована в правом верхнем углу (`position: fixed`) и доступна на любом экране — включая длинное прохождение теста при прокрутке.
- **Адаптивность от 320px до 4K.** Отдельные брейкпоинты для мобильных, планшетов и десктопа, увеличенные зоны клика на тач-устройствах.
- **Доступность.** ARIA-метки, навигация с клавиатуры, поддержка `prefers-reduced-motion` и режима повышенной контрастности (`prefers-contrast: more`).

## Деплой (GitHub Pages)

Публикация настроена через пакет `gh-pages`. Поле `homepage` в `package.json` задаёт базовый путь `/architecture-quiz-app`.

```bash
npm run deploy
```

Команда сначала собирает проект (`predeploy` → `npm run build`), затем пушит содержимое `./build` в ветку `gh-pages`. Сайт обновляется через 1–2 минуты. Сама сборка (`npm run build`) ничего не публикует.

## Добавление новой темы

**Шаг 1.** Создайте `src/data/topics/your-topic.json`:

```json
{
  "topic": "your-topic",
  "version": "1.0.0",
  "totalQuestions": 200,
  "questions": [
    {
      "id": 1,
      "question": "Текст вопроса?",
      "options": ["Вариант A", "Вариант B", "Вариант C", "Вариант D"],
      "correct": 1,
      "explanation": "Почему верен вариант B."
    }
  ]
}
```

**Шаг 2.** Добавьте запись в массив `topics` в `src/data/topics.config.js`:

```javascript
{
  id: 'your-topic',
  name: 'Название темы',
  description: 'Краткое описание',
  icon: 'Code',            // имя иконки lucide-react (см. ICONS в App.js)
  color: '#ec4899',
  file: 'your-topic.json',
  difficulty: 'intermediate', // beginner | intermediate | advanced | beginner-advanced
  tags: ['tag1', 'tag2']
}
```

Поле `totalQuestions` в конфиге не требуется — количество вопросов вычисляется автоматически из файла при загрузке. Тема сразу появится на главном экране.

> Иконки берутся из `lucide-react` через карту `ICONS` в `App.js`. Неизвестное имя иконки автоматически получает запасную, поэтому добавление темы не ломает интерфейс. Чтобы задействовать новую иконку, добавьте её в импорт и в `ICONS`.

## Формат данных

**Вопрос:**

```javascript
{
  id: 1,                      // уникальный, последовательный в пределах файла
  question: "Текст вопроса",
  options: ["A", "B", "C", "D"], // ровно 4 варианта
  correct: 1,                 // индекс правильного варианта (0–3)
  explanation: "Объяснение"   // непустая строка
}
```

**Тема (`topics.config.js`):** `id`, `name`, `description`, `icon`, `color`, `file`, `difficulty`, `tags`. Загрузчики `loadTopicQuestions`, `loadTopicQuestionCount`, `loadAllTopicQuestionCounts` инкапсулируют динамический импорт и подсчёт.

## Темизация

Дизайн-токены — это CSS-переменные в `src/styles/themes.css`, объявленные для `:root[data-theme="light"]` и `:root[data-theme="dark"]`:

```css
:root[data-theme="light"] {
  --primary: #3b82f6;
  --success: #10b981;
  --error: #ef4444;
}
```

Атрибут `data-theme` выставляется на `<html>` из `App.js`, а ранняя инициализация в `index.js` применяет сохранённую/системную тему ещё до первого рендера, чтобы избежать мигания.

## Адаптивные брейкпоинты

- **Mobile:** < 640px — одна колонка, увеличенные зоны клика (мин. 44px), вертикальные кнопки.
- **Tablet:** 640–1023px — две колонки.
- **Desktop:** ≥ 1024px — три+ колонки, hover-эффекты.
- **Large / XL:** ≥ 1280px / ≥ 1536px и далее вплоть до 4K.

На тач-устройствах (`hover: none`) hover-эффекты заменяются на active-состояния.

## Архитектура приложения

Всё приложение — в `App.js`. Корневой компонент `ArchitectureQuizApp` хранит состояние через `useState`:

- `theme` — текущая тема (синхронизируется с `<html>` и `localStorage`).
- `topics` — список тем (с дозагрузкой счётчиков вопросов).
- `selectedTopic`, `questions`, `status` (`idle | loading | ready | error`).
- `started`, `currentIndex`, `answers`, `selected`, `finished` — ход прохождения теста.

Экраны: выбор темы → стартовый экран темы → прохождение вопросов → результаты (плюс состояния загрузки и ошибки). Хелпер `wrap()` оборачивает любой экран в общий контейнер с переключателем темы и подвалом, поэтому кнопка темы доступна везде.

## Известные ограничения

- Динамический импорт тем требует сборщик с поддержкой code splitting (Webpack 5+).
- Прогресс и выбор темы хранятся только локально (`localStorage`); серверной синхронизации нет.
- Offline-режим (PWA) не реализован.
