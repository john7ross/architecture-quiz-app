# Архитектурный Квиз — Масштабируемая версия 2.0

Современное React-приложение для проверки знаний по архитектуре, DDD, DocHub и другим темам.

## 🎯 Что нового в версии 2.0

### ✅ Масштабируемая архитектура
- **JSON-based темы**: каждая тема в отдельном JSON файле
- **Динамическая загрузка**: вопросы загружаются по требованию
- **Конфигурация тем**: централизованное управление через `topics.config.js`
- **Простое добавление новых тем**: добавьте JSON файл + запись в конфиг

### 🎨 Современный UI
- **Темная тема**: автоматическое определение + переключатель
- **Адаптивный дизайн**: от 320px (мобильные) до 4K мониторов
- **Плавные анимации**: с учетом `prefers-reduced-motion`
- **Touch-friendly**: оптимизация для сенсорных экранов

## 📝 Добавление новой темы

### Шаг 1: Создайте JSON файл

Создайте `src/data/topics/your-topic.json`:

```json
{
  "topic": "your-topic",
  "version": "1.0.0",
  "lastUpdated": "2026-06-02",
  "totalQuestions": 100,
  "questions": [
    {
      "id": 1,
      "question": "Ваш вопрос?",
      "options": [
        "Вариант A",
        "Вариант B (правильный)",
        "Вариант C",
        "Вариант D"
      ],
      "correct": 1,
      "explanation": "Объяснение почему B правильный..."
    }
  ]
}
```

### Шаг 2: Добавьте в конфигурацию

Откройте `src/data/topics.config.js` и добавьте:

```javascript
{
  id: 'your-topic',
  name: 'Название темы',
  description: 'Краткое описание',
  icon: 'Code',
  color: '#ec4899',
  file: 'your-topic.json',
  totalQuestions: 100,
  difficulty: 'intermediate',
  tags: ['tag1', 'tag2']
}
```

### Шаг 3: Готово!

Тема автоматически появится на главном экране.

## 🎨 Кастомизация темы

### Цвета

Измените CSS-переменные в `src/styles/themes.css`:

```css
:root[data-theme="light"] {
  --primary: #3b82f6;      /* Основной цвет */
  --success: #10b981;      /* Правильный ответ */
  --error: #ef4444;        /* Неправильный ответ */
}
```

### Breakpoints

Адаптивные точки в `src/styles/responsive.css`:

- **Mobile**: < 640px
- **Tablet**: 640px - 1023px  
- **Desktop**: ≥ 1024px
- **Large**: ≥ 1280px
- **XL**: ≥ 1536px

## 👨‍💻 Разработка

### Структура компонентов

```
QuizApp
├── TopicSelector        # Выбор темы
│   └── TopicCard        # Карточка темы
├── StartScreen          # Стартовый экран
├── QuestionView         # Просмотр вопроса
│   ├── OptionCard       # Вариант ответа
│   └── Explanation      # Объяснение
└── ResultsView          # Результаты
```

### State Management

Использует `useReducer` с действиями:
- `SET_TOPICS` - загрузка тем
- `SELECT_TOPIC` - выбор темы
- `LOAD_QUESTIONS` - загрузка вопросов
- `START_QUIZ` - старт теста
- `ANSWER_QUESTION` - ответ на вопрос
- `NEXT_QUESTION` - следующий вопрос
- `RESTART_QUIZ` - перезапуск
- `BACK_TO_MENU` - возврат в меню
